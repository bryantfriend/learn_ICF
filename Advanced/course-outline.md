# Advanced course outline

1. Register a workflow and identify its dependencies. [Open the first exercise](../studio.html#advanced-orchestrator-map).
2. Classify failures, bound retries and record an audit trail that a maintainer can follow.
3. Design Emit behavior, summarize an incident and gate delivery after Process.
4. Handle duplicate runs, duration budgets and manual review. Use the [Advanced project plan](../studio.html#advanced-project) to describe how your application will recover from failures.

Practice an Emit failure after a committed loan in the [pipeline sandbox](../reference.html#mission). Check the final loan state before deciding which operation to retry.
