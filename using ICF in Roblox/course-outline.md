# Using ICF in Roblox course outline

1. Send an Intent request from a LocalScript, define a shared contract and keep the server handler small. [Open the first exercise](../studio.html#roblox-client-intent).
2. Validate and normalize server inputs, load player context, authorize a purchase, then Process and Emit.
3. Connect successful outcomes to GUI feedback, tools, world objects, animations, sound and effects.
4. Apply the pattern to quests, abilities and reward chests. Account for cooldowns, balances and multiple players.
5. Assemble the shop flow and complete the [Roblox project plan](../studio.html#roblox-project).

The academy checks Luau text patterns. Run the feature in Roblox Studio with an allowed request and a denied request, then inspect the authoritative player state and feedback in both cases.
