How the activities are checked

JavaScript runs in your browser. Some activities check what your code does. Others also check what it prints or how it is written. Roblox activities check the Luau code you type. Run the code in Roblox Studio to see it work. Project plans are checked for the ideas they cover.

This browser remembers your progress, code, and project plans. When you export your work, the file includes your older saved notes.
