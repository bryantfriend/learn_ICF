# JavaScript Foundations course outline

Start with the [library sandbox](../reference.html#mission) to watch a request pass or stop. In the [Foundations studio](../studio.html#foundations-intent-envelope), use **Course menu** to move between exercises.

1. Describe one action with an Intent. Locate its declaration and stage registries.
2. Write validators for strings and amounts, then normalize the validated input.
3. Load context from trusted state, authorize the action, apply the change and emit an audit entry.
4. Compose validators and use the [project plan](../studio.html#foundations-project) to map the same decisions for your own action.

For independent exercises that use the real template runner, continue with the [builder curriculum](../BUILDER_CURRICULUM.md).
