# Composition course outline

1. Separate reusable stage helpers from domain rules. [Open the first exercise](../studio.html#composition-core-domain-boundaries).
2. Compose validators, chain normalizers and build the context needed by an authorization policy.
3. Run a multi-step processor, record its result and audit details, then compose the feature pipeline.
4. Exercise a validator registry, return a predictable rejection and check stage order. Apply these choices to the [Composition project plan](../studio.html#composition-project).

For scored optional evidence inside AddContext, continue with [Adaptive Context](../studio.html#adaptive-boundaries).
